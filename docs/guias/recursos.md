# Recursos

Tudo o que o Aprendiz faz, com o link para a explicação de cada recurso.

| | |
|---|---|
| 💬 **Chat moderno** | Histórico de conversas, tema claro/escuro, Markdown, ícones, responsivo |
| 🎓 **Aprende pelo chat** | `aprenda que a senha do wifi é casa123` · `pergunta: … resposta: …` · `anote: …` · com o addon de compreensão, também `a partir de agora…`, `fica sabendo que…`, `anota aí:…`; quando algo muda, vale o mais recente ([docs](../estudo/compreensao.md#jeitos-de-ensinar-26)) |
| 🔁 **Aprende com correções** | Errou? *Corrigir* transforma a resposta certa em ensinamento |
| 🕸️ **Teia de porquês** | Addons dizem *por que* cada resposta é assim e a que outros conceitos ela se liga, inclusive em outros addons; a resposta **Trabalhada** explica a cadeia até a base ([docs](../estudo/algoritmos.md#8-resposta-trabalhada-e-teia-de-porquês-20)) |
| 🧩 **Entende a frase** | Padrões de frase ("quantos pedidos cada cliente fez" = agrupar e contar), números por extenso ("dois mais dois") e a regra de que a resposta precisa falar do assunto da pergunta ([docs](../estudo/compreensao.md#padrões-de-frase-20)) |
| 🧩 **Addons** | Pacotes `.aprendiz` (memória, linguagem, parâmetros, personalização, compreensão, vetores, norma) com confirmação antes de instalar ([docs](addons.md)) |
| ✍️ **Revisão de texto** | Com um addon de norma: ortografia, gramática e palavras de outras variantes pelo português de cada país (Brasil, Portugal, Angola, Moçambique, Cabo Verde, Guiné-Bissau, São Tomé e Príncipe, Timor-Leste): `revise: …`, `o certo é X ou Y?` e a tela **Revisar texto** ([docs](../estudo/revisao.md)) |
| 🧠 **Compreensão** | Com o addon de compreensão: tipo de pergunta, expressões, formas irregulares, perguntas sobre o próprio app, limites de um assistente offline e indicação do addon certo quando não sabe algo ([docs](../estudo/compreensao.md)) |
| 🧭 **Busca por sentido** | Com o addon de vetores: se a palavra não está na base, tenta as de sentido parecido |
| 📖 **Dicionários** | Respondem nos dois sentidos, "o que significa kota?" e "como se diz dinheiro em Angola?", sem atrapalhar o resto da conversa |
| 🗣️ **Vários jeitos de perguntar** | Addons trazem variações de cada pergunta, que levam à mesma resposta |
| 🧪 **Algoritmo recomendado** | Cada addon traz a busca e a resposta que funcionam melhor com ele, medidas num teste com o próprio conteúdo e com perguntas fora do assunto |
| ✅ **Homologação** | `ferramentas/homologar.py` faz perguntas de gente de verdade contra os addons reais da loja e contra uma base pessoal de exemplo, em Debian, Fedora, Ubuntu e Windows ([docs](../referencia/homologacao.md)) |
| 🗂️ **Grupos de addons** | Addons com a mesma recomendação são ativados juntos, no mesmo padrão de busca; os de apoio (compreensão, diálogo, vetores, personalização) entram no grupo dos addons que complementam |
| 💬 **Diálogo** | Com o addon de diálogo: cumprimento + pedido na mesma frase, desabafo, pedido de opinião, perguntas reflexivas e reações à resposta anterior ("não entendi", "não era isso", "sim", "e em Portugal?") ([docs](../estudo/compreensao.md#diálogo)) |
| 📦 **Exporta o que você ensinou** | Gera um addon para compartilhar, escolhendo item a item; dados pessoais vêm desmarcados |
| 🎨 **Configurações** | Limiares, algoritmos padrão, nome, cor e boas-vindas do assistente |
| 🔍 **Seletor de algoritmos** | 5 de busca e 3 de resposta, cada um com explicação no botão **?** |
| 📈 **Busca Calibrada** | Regressão logística treinada com as perguntas dos addons; a confiança é a chance de acerto ([docs](../estudo/algoritmos.md#5-calibrado-buscacalibradopy-pesos-aprendidos-24)) |
| 🖥️ **Monitor** | O pipeline ao vivo, a conta da busca, os parâmetros do modelo, o desempenho e um glossário, em nível Iniciante ou Avançado ([docs](../estudo/monitor.md)) |
| 🛡️ **Modo estrito** | Se não sabe, diz que não sabe |
| ❔ **Resposta "incerto"** | "Senha do **banco**" com só a senha do wifi na base: avisa que não tem e mostra o mais perto, em vez de responder como se fosse a mesma coisa ([docs](../estudo/compreensao.md#especificador-que-falta-a-resposta-incerto-27)) |
| 👍 **Aprende com você** | 👍/👎, "não era isso" e Corrigir ajustam a busca Calibrada no próprio aparelho; o ajuste pode ir para outra máquina como addon ([docs](../estudo/algoritmos.md#ajuste-pessoal-a-calibrada-aprende-com-você-26)) |
| 🗣️ **Banco de linguagem** | Abreviações, sinônimos e intenções editáveis pela interface |
| 📄 **Importa arquivos** | `.txt` e `.md`, divididos automaticamente em trechos |
| ♻️ **Reset com backup** | Volta ao estado inicial, salvando antes uma cópia de segurança completa |
