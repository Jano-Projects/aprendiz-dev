Base de conhecimento

Addons

Addons são pacotes prontos (conhecimentos, linguagem, parâmetros ou personalização): baixe um arquivo .aprendiz e importe aqui. Antes de instalar, você vê o que ele traz. Desativar um addon só o esconde; nada é apagado. O que você ensina e configura tem sempre prioridade.

Instalar addon

Exportar como addon

Gera um arquivo .aprendiz com o que você marcar, para compartilhar. Itens com cara de dado pessoal (senhas, e-mails, telefones, números longos…) vêm desmarcados: revise antes de marcar. Addons instalados entram só como dependências (nome e versão), sem copiar o conteúdo deles. Todo addon exportado é marcado como de terceiros.

Como funcionam os algoritmos

Cada resposta passa por duas etapas: a busca encontra os conhecimentos mais parecidos com a pergunta, e a resposta monta o texto final. Troque os algoritmos no topo da tela e use Por que respondi isso? para ver os números.
